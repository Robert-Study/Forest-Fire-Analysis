# Forest Fire Model

Library-style code extracted from the original notebook and organised into modules.

- No code runs automatically on import.
- Call functions explicitly from your own scripts/notebooks.

## Structure
- `code/core_simulations/`: simulation update functions + run loops
- `code/analysis/`: fitting, sweeps, and analysis helpers
- `code/display/`: plotting / GIF utilities
- `outputs/`: default output location (gitignored)
